# HR Jobs Kerala

A simple GitHub Pages website to discover HR, recruitment, payroll and
talent-acquisition jobs across Kerala.

Special focus:

- Remote HR jobs
- Kozhikode
- Thrissur
- Palakkad
- Shoranur
- Cherpulassery
- Ottapalam

## Features

- Filter jobs by keyword, location, work mode and source
- Quick search links to major Indian and global job platforms
- GitHub Actions-based scheduled updates
- Free hosting through GitHub Pages

## Important note

This project does not scrape websites that prohibit automated access.
It uses direct search links and, where available, official APIs or RSS feeds.

Always apply through the original employer or job-platform website.

## Setup

1. Create a GitHub repository.
2. Upload these files.
3. Go to Settings → Pages.
4. Choose `main` branch and `/ (root)`.
5. Save.
6. Open the GitHub Pages URL.

## Updating jobs

The GitHub Action runs automatically three times daily.
You can also run it manually from the **Actions** tab using
**Update HR jobs → Run workflow**.
